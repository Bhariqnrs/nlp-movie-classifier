# NLP Movie Rating Classifier

## Stack
- Pure HTML + CSS + JavaScript (no framework)
- TensorFlow.js (via CDN) untuk NLP model
- Universal Sentence Encoder untuk embedding teks
- Klasifikasi rating: ⭐ 1–5 bintang

## Fitur
1. Input review teks film
2. Analisis sentimen real-time
3. Prediksi rating 1–5 bintang
4. Visualisasi confidence score
5. Keyword/feature extraction highlight
6. History klasifikasi
7. Demo dataset film populer

## UI Design
- Dark mode glassmorphism
- Gradient purple-cyan
- Animasi typing & loading
- Star rating animation
- Confidence bar chart
